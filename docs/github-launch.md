# GitHub 发布与引流清单

这份清单是给开源版仓库准备的，目标不是只把代码传上去，而是让仓库能持续带来：

- Star
- Demo 访问
- 私域咨询
- 商务合作线索
- 渠道伙伴

## 1. 仓库基础信息

建议你在 GitHub 仓库设置里补齐：

- 仓库名称：`open-creative-studio` 或你自己的品牌名
- Description：`Open-source AI creation studio for Volcengine and Alibaba Cloud video/image models`
- Website：填你的演示站
- Topics：`aigc`, `nextjs`, `video-generation`, `image-generation`, `volcengine`, `aliyun`, `seedance`, `wan2-7`

## 2. README 必放内容

- 项目定位
- 已接入模型
- 核心功能
- 快速开始
- 部署流程
- 商业支持
- 联系方式

## 3. 最容易承接咨询的文案

你可以直接放在 README、首页、置顶 issue 或 discussion：

> 如果你正在做 AI 创作平台、工作室工具、企业私有化部署，或者需要阿里云 / 火山引擎模型接入支持，欢迎联系我获取渠道资源、部署支持和定制化方案。

## 4. 最建议公开的联系方式

- 微信
- 邮箱
- 公众号
- 官网 / 着陆页

建议至少保留两个渠道，避免用户只想咨询却找不到你。

## 5. 建议做的引流入口

- 首页商业支持卡片
- README 商务合作板块
- 演示站页脚联系方式
- GitHub Profile README
- 掘金 / 知乎 / 公众号文章中的仓库链接

## 6. 最适合拿来获客的服务项

- 多模型平台私有化部署
- API Key 配置与安全隔离
- 任务队列、轮询、回调稳定性改造
- 阿里云 / 火山引擎 / 聚合平台统一接入
- 品牌 UI 定制
- 支付系统、额度系统、邀请码系统

## 7. 发布前最后检查

- 没有提交真实 `.env`
- 没有提交真实数据库文件
- 没有提交真实 API Key
- README 中仓库地址、演示地址、联系方式都已替换
- 首页联系信息已填写 `NEXT_PUBLIC_CONTACT_WECHAT` / `NEXT_PUBLIC_CONTACT_EMAIL`

## 8. 推荐发布节奏

1. 先发 GitHub 仓库
2. 再发演示站
3. 同步发一篇“我开源了一个国内双厂商 AI 创作平台”的文章
4. 把文章同步到掘金、知乎、公众号、即刻、X
5. 收集首批使用者反馈，再迭代 README 和案例
